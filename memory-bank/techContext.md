# Contexto técnico

## Pila tecnológica

- **HTML** para la estructura semántica de las páginas y componentes web.
- **CSS** y **Tailwind CSS** para estilos, diseño responsive y consistencia visual.
- **JavaScript** para la interacción, validaciones y lógica de interfaz.

## Reglas de validación

- La consola del navegador debe quedar sin errores después de ejecutar los flujos relevantes.
- Los atributos de formularios y sus expresiones regulares deben ser válidos y no producir errores de RegEx.
- Los cambios deben registrarse en `memory-bank/progress.md` antes de realizar un commit.
- Deben respetarse `AGENTS.md`, `.agents/development-rule.md` y los archivos protegidos del repositorio.
