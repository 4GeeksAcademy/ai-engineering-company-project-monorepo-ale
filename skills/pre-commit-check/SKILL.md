# Skill: Verificación Pre-Commit (Pre-Commit Check)

## 1. Objetivo Único y Definido
Validar la calidad del código, asegurar ausencia de errores en consola y actualizar el banco de memoria antes de hacer commit.

## 2. Inputs Documentados

- Archivos Modificados: Resultado de git status.
- Estado de Memoria: Archivo memory-bank/progress.md.

## 3. Criterios de Aceptación Explícitos y Verificables

- [ ] Sin errores en la consola del navegador.
- [ ] Atributos de formularios sin errores de RegEx.
- [ ] Actualización registrada en memory-bank/progress.md.
